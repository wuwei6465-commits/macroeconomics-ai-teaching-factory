## 约束要求

### 目标问题链
题目必须按"基本、重点、难点、实践、拓展"五类逻辑分布：

| 类型 | 数量 | 布鲁姆能级 | 考查目标 |
|------|------|-----------|---------|
| **基本问题** | 2道 | L1-L2 | 概念理解、定义识别 |
| **重点问题** | 3道 | L3-L4 | 原理应用、推导分析 |
| **难点问题** | 2道 | L4-L5 | 思辨能力、复杂分析 |
| **实践问题** | 2道 | L4-L5 | 案例分析、现实应用 |
| **拓展问题** | 1道 | L5-L6 | 综合评价、创新设计 |

### 难度梯次
- 确保 L3（运用）及以上能级的题目占比不少于 60%
- 每道题标注难度等级（易/中/难）和布鲁姆能级（L1-L6）

### 理实融合
- 实践与拓展问题必须结合【课程相关实践背景】
- 引导学生分析【理论】与【实践】的关系
- 融入【课程思政元素】

### 非 AI 味
- 题目描述需具备专业教材的严谨性
- 避免常识性废话
- 数学公式使用 LaTeX 格式

## 设计理念说明

### 目标问题链设计

借鉴马胜楠（2025）"五类目标问题"设计理念：

1. **基本问题**：夯实基础，确保所有学生掌握核心概念
2. **重点问题**：突出核心，训练学生运用原理解决问题的能力
3. **难点问题**：突破瓶颈，培养学生分析复杂问题的思辨能力
4. **实践问题**：联系实际，引导学生将理论应用于现实案例
5. **拓展问题**：开阔视野，激发学生创新思维和综合评价能力

### 布鲁姆分类法应用

| 能级 | 动词关键词 | 题型示例 |
|------|-----------|---------|
| L1 记忆 | 列举、定义、识别 | 概念填空、名词解释 |
| L2 理解 | 解释、归纳、举例 | 简答题、概念辨析 |
| L3 运用 | 计算、演示、应用 | 计算题、公式应用 |
| L4 分析 | 比较、对比、推导 | 分析题、推导证明 |
| L5 评价 | 评判、评估、辩论 | 案例分析、政策评价 |
| L6 创造 | 设计、构建、规划 | 开放题、方案设计 |

支持特性：
- MathJax数学公式渲染
- 折叠式答案解析
