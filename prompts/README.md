# Prompt 设计规范

本目录包含"宏观经济学AI教学资源工厂"的核心Prompt模板，展示了如何将教育理论（BOPPPS、OBE、布鲁姆分类法等）转化为AI可执行的结构化指令。

---

## 🎯 设计理念

### 教育理论数字化封装

传统教育理论（如BOPPPS）是描述性的，教师需要自行理解和应用。本项目的创新在于将其**转化为结构化的AI指令**：

```
教育理论（描述性）
    ↓ 数字化封装
Prompt模板（指令性）
    ↓ AI执行
教学资源（产出）
```

### 核心设计原则

1. **结构化**：所有输出遵循统一的元数据格式（Frontmatter）
2. **标准化**：BOPPPS六环节、布鲁姆六层级、五问设计链
3. **可验证**：每个环节都有明确的评价标准和输出要求
4. **可复用**：模板与内容分离，适用于不同课程主题

---

## 📝 使用方式

### 在TRAE CN中使用

1. 打开TRAE CN，创建新的Skill
2. 将Prompt模板内容复制到Skill的system prompt中
3. 调用Skill时，传入具体参数（如`{{第X次课}}`）
4. AI按照模板规范生成教学资源

### 直接使用

1. 将模板中的占位符（如`{{第X次课}}`、`【主题名称】`）替换为实际内容
2. 将完整Prompt发送给AI（DeepSeek、Kimi、GPT等）
3. AI按照约束要求生成输出

## 📚 参考理论

- **BOPPPS模型**：Bridge-in → Objective → Pre-assessment → Participatory Learning → Post-assessment → Summary
- **OBE理念**：Outcome-Based Education，以学习成果为导向
- **布鲁姆分类法**：记忆→理解→运用→分析→评价→创造
- **建构主义**：情境创设、主动建构、协作学习
