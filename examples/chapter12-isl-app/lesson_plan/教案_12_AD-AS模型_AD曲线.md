# 教学主题：AD-AS模型（AD曲线）

## 一、知识框架图

```
总需求理论
├─ AD曲线的推导（从IS-LM模型）
│  ├─ 物价水平P变动
│  ├─ 实际货币余额M/P变动
│  ├─ LM曲线位移
│  └─ 均衡产出Y变动
├─ AD曲线的形状
│  └─ 向右下方倾斜
│     ├─ 实际余额效应
│     ├─ IS曲线效应
│     └─ 汇率效应（开放经济）
├─ AD曲线的位移
│  ├─ 右移因素：G↑, M↑, T↓, 信心↑
│  └─ 左移因素：G↓, M↓, T↑, 信心↓
└─ 特殊情形
   ├─ 挤出效应
   └─ 流动性陷阱
```

## 二、核心教学要点

### 1. 从IS-LM模型推导AD曲线
- 推导逻辑：物价 $P$ 变动 → 实际货币余额 $M/P$ 变动 → $LM$ 曲线位移 → 均衡 $Y$ 变动
- 数学表达：$Y = Y(P)$，其中 $P$ 与 $Y$ 负相关

### 2. AD曲线向下倾斜的原因
- **实际余额效应**：物价上升 → 实际货币余额减少 → 消费和投资减少 → 产出下降
- **庇古效应**：物价下降 → 实际货币余额增加 → 消费者感到更富有 → 增加消费
- **汇率效应**：物价上升 → 本币升值 → 净出口减少 → 产出下降

### 3. AD曲线的位移
- **右移因素**：
  - 扩张性财政政策：$G \uparrow$ 或 $T \downarrow$
  - 扩张性货币政策：$M \uparrow$
  - 消费者信心增加
- **左移因素**：上述因素的相反方向

### 4. 挤出效应
- 定义：财政扩张引起利率上升，从而减少投资支出，抵消了部分产出增长
- 传导链条：$G \uparrow \rightarrow Y \uparrow \rightarrow L(r,Y) \uparrow \rightarrow r \uparrow \rightarrow I \downarrow$

### 5. 流动性陷阱
- 定义：当名义利率降至零下限，货币政策无法再通过降低利率刺激投资
- 表现：LM曲线在零利率位置变为水平线
- 政策启示：需要强有力的财政政策或前瞻性指引

## 三、课堂活动设计

### 1. 复习导入（10分钟）
- 提问：AS曲线是如何推导的？
- 讨论：粘性价格模型的核心机制是什么？

### 2. 新课引入（10分钟）
- 展示美国大萧条时期物价与产出数据
- 引出问题：为什么物价下降会导致产出下降？

### 3. 主讲授环节1（30分钟）
- 讲解IS-LM模型到AD曲线的推导
- 分析物价水平变动的实际余额效应
- 使用交互实验展示AD曲线生成过程

### 4. 实验操作（20分钟）
- 运行Jupyter实验：IS-LM推导AD
- 观察物价水平变动如何影响均衡产出

### 5. 主讲授环节2（20分钟）
- 讲解AD曲线的位移因素
- 分析挤出效应与流动性陷阱
- 讨论政策搭配

### 6. 总结（10分钟）
- 回顾AD曲线的核心要点
- 强调AD与AS的结合是宏观经济分析的基础
