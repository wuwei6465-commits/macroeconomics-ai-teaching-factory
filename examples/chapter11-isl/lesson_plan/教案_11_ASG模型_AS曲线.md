# 教学主题：AD-AS模型（AS曲线）

## 一、知识框架图

```
总供给理论
├─ 短期总供给曲线 (SRAS)
│  ├─ 粘性价格模型
│  │  ├─ 期望价格：p = P + a(Y - Ȳ)
│  │  └─ 粘性价格企业：p = EP
│  ├─ 不完全信息模型
│  │  ├─ 相对价格混淆
│  │  └─ 产出对意外物价的反应
│  └─ 总供给方程：Y = Ȳ + α(P - EP)
├─ 长期总供给曲线 (LRAS)
│  ├─ 垂直于自然产出水平
│  └─ 不受物价水平影响
└─ 预期的作用
   ├─ 适应性预期
   └─ 理性预期
```

## 二、核心教学要点

### 1. 总供给曲线的定义
- 总供给曲线描述了在不同物价水平下，企业愿意生产和销售的产出总量
- 短期总供给曲线向上倾斜，长期总供给曲线垂直

### 2. 粘性价格模型
- 假设企业具有市场力量（垄断竞争）
- 部分企业因合同、菜单成本等原因无法迅速调整价格
- 当实际物价高于预期物价时，粘性价格企业的产品相对便宜，销量增加，产出上升

### 3. 不完全信息模型
- 假设供应商混淆了物价总水平变动与自身产品相对价格变动
- 当物价意外上升时，供应商误以为是自身产品需求增加，从而增加产出

### 4. 总供给方程
$$Y = \bar{Y} + \alpha(P - EP)$$
- $Y$：实际产出
- $\bar{Y}$：自然产出水平
- $P$：实际物价水平
- $EP$：预期物价水平
- $\alpha$：产出对物价意外变动的反应程度

### 5. 预期的影响
- 预期物价水平 $EP$ 的变动会导致总供给曲线平移
- 当 $P = EP$ 时，产出等于自然产出水平

## 三、课堂活动设计

### 1. 复习导入（10分钟）
- 提问：IS-LM模型的均衡条件是什么？
- 讨论：如果物价水平发生变化，会如何影响IS-LM模型的均衡？

### 2. 新课引入（10分钟）
- 展示美国实际GDP与物价水平的历史数据
- 引导学生观察产出与物价的关系

### 3. 主讲授环节1（30分钟）
- 讲解总供给曲线的基本概念
- 推导短期总供给方程
- 分析物价水平与产出的关系

### 4. 实验操作（20分钟）
- 运行Jupyter实验：调节预期物价EP滑块
- 观察SRAS曲线如何随预期平移

### 5. 主讲授环节2（20分钟）
- 讲解粘性价格模型
- 讲解不完全信息模型
- 对比两种模型的异同

### 6. 总结（10分钟）
- 回顾总供给理论的核心要点
- 强调预期在总供给中的重要作用
